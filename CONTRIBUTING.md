# Contribuir

Primero reproduce el escenario. Mantén los datos sintéticos y los fallos deliberados en sus overlays.
Un cambio de infraestructura debe pasar las tres validaciones del README. Si cambias un contrato,
actualiza especificación, casos de aceptación y documentación en el mismo PR.

No añadas dependencias solo para una demo, resultados atribuidos a un modelo que no ejecutaste,
credenciales, screenshots de clientes ni actividad simulada presentada como colaboración real.
Los issues de ensayos deben indicar entorno, prompt, resultado esperado y observado.
