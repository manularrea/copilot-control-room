# Exploración rápida

Investiga de forma autónoma dentro del alcance de TICKET.md. Puedes iterar la solución
sin presentar cada paso intermedio; conserva tests, datos y contratos.
Documenta hipótesis descartadas y cambios propuestos fuera de alcance, sin aplicarlos.
Las mismas reglas rojas se mantienen. No se habilita autoaprobación ni acceso de red.
Este perfil sirve para comparar dirección y evidencia, no para garantizar fallos del agente.
